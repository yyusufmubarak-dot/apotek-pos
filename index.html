Konfigurasi Cloud Firebase (Sinkronisasi Multi-Device)

Hubungkan apotek ke Google Cloud Firestore (100% Gratis Spark Plan)

ℹ️ Cara Mendapatkan Konfigurasi Firebase Gratis (2 Menit):
  1. Buka console.firebase.google.com dan login dengan akun Google Anda.
  2. Klik "Add Project" (beri nama bebas, misal: Apotek-Medika).
  3. Klik ikon Web (</>) untuk mendaftarkan web app, lalu salin nilai firebaseConfig ke kolom di atas.
  4. Di menu samping, buka Build > Firestore Database, klik Create Database, dan pilih Start in test mode. Selesai!
